Generate DS-Ready MEI

Upload an MEI, MusicXML, or MuseScore file and generate a Digital Splitleaf compatible MEI file.

What This Transformer Applies

  • Creates/updates workList/work with title, metre (otherChar), and 4 incipit codes: plaineAndEasie, pitchclass, signedinterval, contour.
  • Replaces existing layerDef and instrDef within each staffDef using SATB mapping.
  • Normalizes lyric syllables to empty <syl/> elements.
  • Sets each note/@class to a URI reference based on @xml:id (for example, #n123).

Recommended input is MEI Basic exported from MuseScore. MusicXML/MuseScore conversion requires converter binaries configured in run-mei-generator.xq.
