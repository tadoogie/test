Generate TEI From Text File

Upload a .txt file and run the TEI generator on the server.

Formatting Guidelines

  • Optional edition metadata can go at the top of the file (before the first psalm), with one key-value pair per line.
  • Long Title: full edition name shown in TEI header, e.g. Long Title: The Psalms of David in Metre.
  • Short Title: abbreviated citation title, e.g. Short Title: Psalms in Metre.
  • Publisher: publishing body or editor, e.g. Publisher: Free Church of Scotland.
  • Date: publication year or full date, e.g. Date: 1650 or Date: 1650-01-01.
  • Licence: licence/copyright text for <publicationStmt>, e.g. Licence: Copyright, Free Church of Scotland (reproduced with permission).
  • License URI: link target for <licence target=\"...\">, e.g. License URI: https://freechurch.org/praise-resources/.
  • Description: source description text for <sourceDesc>, e.g. Description: Texts from the Sing Psalms, 2003..
  • If a metadata field is omitted or left blank, a default value is used by the generator.
  • Each psalm must start with Psalm <id> (<metre>), for example Psalm 21 (CM).
  • Leave a blank line after each psalm header.
  • Separate stanzas with a blank line.
  • The first line of each verse should start with a number: 1 ..., 1. ..., or 1) ....
  • Valid metres are CM, LM, SM, or numeric patterns like 8.6.8.6.
  • Use plain UTF-8 text without tabs.

Example full file (metadata + psalm text): 

Long Title: The Psalms of David in Metre
Short Title: Psalms in Metre
Publisher: Free Church of Scotland
Date: 1650
Licence: Public Domain
License URI: https://example.org/license
Description: Texts from the 1650 Scottish Psalter.

Psalm 21 (CM)

1 The king in thy great strength, O Lord,
Shall very joyful be;
In thy salvation rejoice
How vehemently shall he!

2 Thou hast bestowed upon him all
That his heart would request;
And thou from him didst not withhold
Whate'er his lips expressed.
