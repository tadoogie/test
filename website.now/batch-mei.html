Generate DS-Ready MEI — Batch

Upload a zip of MEI files (folders and subfolders are fine) and get back a zip of Digital Splitleaf compatible MEI with the same folder structure. Nothing is added to the database. For a single file, use the upload form.

What This Batch Transformer Applies

  • Everything the single-file generator does: workList/work with title, metre and the four incipit codes; SATB layerDef/instrDef; empty <syl/>; note/@class URI references.
  • Title and metre are read from each file’s <anchoredText func="title">: the bold text is the tune name (capitals become title case, e.g. EARNEST PRAYER → Earnest Prayer) and the rest is the metre (6 6 6 6 8 8 → 6.6.6.6.8.8.).
  • The title heading is removed from the music; <anchoredText func="composer"> is kept.
  • Each Name.mei or Name.xml becomes Name-ds.xml in the matching folder. The zip also contains a CSV report of every file, next to (not inside) the converted folder.

Only MEI is converted; other XML (e.g. MusicXML) is reported and left out, and macOS __MACOSX and hidden files are skipped.

The result page lists each file with the title and metre it found, with a button to download the converted zip.
